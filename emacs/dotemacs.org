  The constant gc-cons-threshold defines the amount of bytes  allowed by
  the garbage collector to be left "hanging". This lines slightly expand
  said threshold during Emacs starup for a reason: starting up the editor,
  loading archives, packages and dependencies requires lots of memory,
  thus aggressively garbage collecting during such a phase introduces an
  important i/o overhead.

  #+begin_src emacs-lisp
    ; temporally extend garbage collector's threshold
    (setq gc-cons-threshold 100000000)
    (message "[CIRO]: Increasing garbage collecting threshold...")
    (add-hook 'after-init-hook
    	  (lambda () (setq gc-cons-threshold 800000)))
    (message "[CIRO]: Decreasing garbage collecting threshold...")
  #+end_src

*** slime

  SLIME (Superior Lisp Interaction Mode for Emacs) is a powerful Emacs extension
  that turns the editor into a full-featured Common Lisp developement
  environment. It achieves that by connecting Emacs to a running Lisp process
  through a component called Swank, enabling interactive developement where the
  programmer can evaluate expressions, inspect objects, compile and run a
  program, without ever leaving the editor, through and integrated REPL:

  #+begin_src emacs-lisp
    ; SLIME setup
    (use-package slime
      :ensure t
      :config
      (setq inferior-lisp-program "sbcl")
      (slime-setup '(slime-fancy)))

    ; provides file-contextual autocompletion
    (use-package slime-company
      :ensure t
      :after (slime company)
      :config
      (setq slime-company-completion 'fuzzy))
  #+end_src

** org-roam

  Org-Roam is a note-taking package built on top of Org Mode that implements the
  Zettelkasten methodology inside Emacs. It treats each note as a node in a
  network of interconnected files, tracking backlinks and relationships between
  them, and optionally visualizing the whole knowledge graph. It is heavily
  inspired by the Roam Research app and is widely used for building personal
  knowledge bases. Further documentation can be found on the [[https://www.orgroam.com/manual.html][official website]]:

  #+begin_src emacs-lisp
    ; org-roam setup
    (use-package org-roam
        :ensure t
        :custom
        (org-roam-directory org-dir-path)
        (org-roam-completion-everywhere t)
        :bind
        (("C-c n l" . org-roam-buffer-toggle)
         ("C-c n f" . org-roam-node-find)
         ("C-c n i" . org-roam-node-insert)
         :map org-mode-map
         ("C-M-i" . completion-at-point))
        :config
        (org-roam-setup))
  #+end_src

*** pass

  The standard Unix password manager.
  Pass manages a directory (usually ~/.password-store/) where each password is
  stored as a GPG encrypted text file. In this system file names are the actual
  entries (e.g. ~/.password-store/email/gmail.gpg), while files content is plain
  , encrypted, text where, usually, the actual password is stored in the first
  line and further line can store any other information (e.g. username:, url:).
  The root directory of said system (i.e. ~/password-store/) is generated as a
  Git repository:

  #+begin_src emacs-lisp
    ; wrapper package for Unix standard password manager
    (use-package pass
      :ensure t
      :after password-store)

    ; clear clipboard after 15s
    (setq password-store-time-before-clipboard-restore 15)
  #+end_src

*** password-store

  The official Emacs's pass binding. This package implements an interface that
  allows the user to use 100% of pass functionalities while never quitting Emacs
  , thus increasing productivity. This is achieved by launching directly pass
  queries and functions through shell-command:

  #+begin_src emacs-lisp
    ; official emacs's pass binding
    (use-package password-store
      :ensure t)
  #+end_src

*** auth-source-pass

  Emacs's built-in system for credential management. It provides an integration
  (or middleware) between Emacs and any other credential management system
  (e.g. Magit uses it for Git credentials, TRAMP uses it for SSH/FTP, mu4e uses
  it for IMAP/SMTP). While the default package (i.e. auth-source) looks for
  credentials in files lile ~/.authinfo.gpg, auth-source-pass wraps this limited
  functionality and resolves credentials queries also using the pass package:

  #+begin_src emacs-lisp
    ; emacs's built-in system for credential management
    (use-package auth-source-pass
      :config
      (auth-source-pass-enable))
  #+end_src

** Magit

  Magit is a full-featured Git interface for Emacs, built as a major mode that
  provides an intuitive and efficient alternative to the standard command-line
  Git workflow. It exposes all of Git's core functionality — staging,
  committing, branching, rebasing, stashing and more — through a clean,
  keyboard-driven interface that lets the user perform complex version control
  operations without ever leaving the editor. Because it is deeply integrated
  with Emacs, it naturally benefits from the editor's existing infrastructure,
  including auth-source for credential management and any custom keybindings or
  workflows the user has already set up:

  #+begin_src emacs-lisp
    (use-package magit
      :ensure t
      :bind
      (("C-x g"   . magit-status)
       ("C-x M-g" . magit-dispatch))
      :config
      ; uses auth-source-pass for authentication
      (setq magit-process-find-password-functions
            '(magit-process-password-auth-source)))
  #+end_src

* My Functions

  The defined function checks for the current buffer to be emacs's org
  configuration file, if so it automatically tangles each code block in the
  emacs-lisp emacs's configuration file. Adding an after-save hook allows to
  check for any saved buffer to be checked automatically:

  #+begin_src emacs-lisp
    ;; ====================| MY FUNCTIONS |====================
  #+end_src

  #+begin_src emacs-lisp
    ; my/tangle dotfiles
    ;
    ; this function autotangles the org config file
    (defun my/tangle-dotfiles ()
      (when (equal (buffer-file-name)
    	       (expand-file-name "~/dotfiles/emacs/dotemacs.org"))
        (org-babel-tangle)
        (message "[CIRO]: Org Configuration file tangled!")))

    (add-hook 'after-save-hook #'my/tangle-dotfiles)
  #+end_src

  #+begin_src emacs-lisp
    (defun my/org-center-latex ()
      (dolist (ov (overlays-in (point-min) (point-max)))
        (when (and (eq (overlay-get ov 'org-overlay-type) 'org-latex-overlay)
          (my/org-latex-block-p ov))
          (overlay-put ov
            'before-string
            (propertize " " 'display (my/build-space ov))))))

    (defun my/build-space (overlay)
      `(space :align-to (- center ,(/ (my/get-image-width-px overlay)
                                       2
                                       (frame-char-width)))))

    (defun my/get-image-width-px (overlay)
      (car (image-size (overlay-get overlay 'display) t)))

    (defun my/org-latex-block-p (overlay)
      (let ((text (buffer-substring-no-properties
                    (overlay-start overlay)
                    (overlay-end overlay))))
        (or (string-match-p "\\`\\s-*\\$\\$" text)
            (string-match-p "\\`\\s-*\\\\\\[" text)
            (string-match-p "\\`\\s-*\\\\begin{" text))))

    ;; (add-hook 'org-mode-hook
    ;;   (lambda ()
    ;;     (add-hook 'after-save-hook #'my/org-center-latex nil t)))

    (advice-add 'org-latex-preview :after
      (lambda (&rest _) (my/org-center-latex)))
  #+end_src
